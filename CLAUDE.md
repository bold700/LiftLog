# LiftLog

Onderdeel van bold700. Gedeelde agents, skills en huisregels komen uit de plugin `bold700-core` (bron: https://github.com/bold700/hq). Typ `/hq` voor het overzicht.

## Dit project
- Wat het is: trainingslogboek voor personal trainer en sporter; React + Vite + TypeScript, Firebase (Firestore, storage), Capacitor voor iOS en Android, API op Vercel.
- Cluster: fitness (agents: `fitness-domain`, `ux-reviewer`, `code-reviewer`)
- Starten: `npm install && npm run dev`
- Checks voor een push: `npm run check` (typecheck, lint, tests)
